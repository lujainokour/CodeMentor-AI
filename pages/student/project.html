Your project brief

Build a console application that helps a student add, view and complete study tasks.

Required behaviour

  1. Show a menu to add a task, list tasks, complete a task or exit.
  2. Store tasks in a list of dictionaries. Each task has an ID, title and completion status.
  3. Assign a unique ID to each new task. Reject empty titles.
  4. Display each task’s ID, title and status. Handle an empty task list.
  5. Complete a task using its ID. Handle invalid and already completed IDs.
  6. Handle invalid menu choices without crashing. Continue until the user chooses to exit.

Data stays in memory. Saving tasks to a file is not required.

Organize your program.

Use these functions to separate the main responsibilities: 

add_task(tasks)
list_tasks(tasks)
complete_task(tasks)
main()

main() owns the menu loop and calls the other functions.

What a successful submission includes.

  • All required behaviour works
  • Invalid input is handled clearly
  • Functions and variable names are understandable
  • README instructions explain how to run the program

Make it your own.

Focus on a clear, reliable console experience before adding optional features.
