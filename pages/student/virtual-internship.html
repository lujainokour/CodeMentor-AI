School Management System in C#

Your role: junior developer practising requirements analysis, implementation and documentation.

Client problem: a fictional school tracks students, teachers and classes in separate lists. Build a small C# console application that keeps these records consistent and makes class rosters easy to find.

Requirements and scope

  • Use C# classes for students, teachers, class groups and enrollments, with unique IDs.
  • Add, view, edit and remove student and teacher records with input validation.
  • Create class groups, assign a teacher, enroll students and display class rosters without duplicate enrollments.
  • Explain and enforce what happens when deleting a referenced student, teacher or class.
  • Save and reload local JSON data. Handle missing and malformed files explicitly.
  • Use fictional records only; do not include real children's data, credentials or personal information.

Required deliverables

  • A GitHub repository containing your C# console project and fictional sample data.
  • A README with prerequisites, setup/run commands, model explanation and usage examples.
  • A checklist of manual tests and their actual results, plus known limitations. Automated tests may be included if you write them.

Suggested implementation steps

  1. Review the requirements and design the model and menus.
  2. Implement record management, class assignment and enrollment validation.
  3. Add JSON persistence and error handling.
  4. Run your checks locally, document limitations and save your repository link below.
  5. Use the sample review as a checklist, revisit the requirements and update your link or notes when needed.

Build and run your code in your own C# development environment. This website cannot run, fetch or inspect your repository.
