# CodeMentor AI

منصة تعليم برمجة تجريبية تضم مسارات ودروسًا وتدريبات، ومساحة للطالب، وخدمات طلابية، ومعاينة لإدارة المحتوى.

**التقنيات:** HTML وCSS وJavaScript، دون اعتماد على حزم أو خادم خلفي.

## التشغيل

من هذا المجلد على Windows:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File start-server.ps1
```

افتح <http://127.0.0.1:8765/>. أوقف الخادم بـ `Ctrl+C`. يمكن أيضًا استخدام أي خادم ملفات ثابتة يجعل هذا المجلد جذر الموقع.

## تجربة المشروع

- حساب الطالب: `student@example.com`
- كلمة المرور: `DemoStudent123!`
- معاينة الإدارة: `pages/admin/admin-dashboard.html`، دون حساب إداري أو مصادقة حقيقية.

## حدود النسخة المحلية

تُحفظ سجلات التعلّم والمحتوى والطلبات التجريبية في المتصفح؛ يرتبط معظمها بالتبويب، وتُحفظ تفضيلات المظهر محليًا. لا توجد مزامنة أو قاعدة بيانات أو حماية حسابات فعلية. التسجيل واستعادة كلمة المرور محاكاة محلية.

ردود المرشد وتقييم الكود والمشروعات أمثلة معدّة مسبقًا؛ لا يوجد اتصال بذكاء اصطناعي حي أو تنفيذ للكود. الحجز والدفع وإصدار الشهادات والتدريب الافتراضي محاكاة، ولا تُرسل الطلبات إلى جهات خارجية. بعض اللغات معروضة دون محتوى تعليمي كامل. روابط المصادر الخارجية تحتاج إلى الإنترنت.

مصادر الدروس منسوبة إلى أصحابها داخل الموقع؛ انظر [المصادر](SOURCES.md). تبقى حقوق المواد الخارجية وتراخيصها لأصحابها.
